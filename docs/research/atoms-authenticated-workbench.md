## 登录后首页工作台

### 已验证

1. 左侧显示工作区/账户上下文，以及首页、资源、我的项目、文件夹和最近项目入口。
2. 页面显示积分或额度相关信息，并提供升级、获取积分或邀请入口。
3. 主操作区包含自然语言输入、`构建`模式、语音入口、发送按钮和 Agent roster；实测页面显示 8 个 Agent。
4. 页面提供连接器推荐区，以及“发现 / 我的项目 / 模板”内容入口。
5. 用户提供的截图补充确认了工作区切换器、创建文件夹、积分余额和上述首页布局。截图中的文字输入不作为本次测试指令。

### 待确认

## 真实生成链路

### 测试输入

```text
请生成一个单页 Stars 项目介绍页，包含一个按钮，点击后在页面上切换欢迎语。使用纯 HTML、CSS 和 JavaScript，不连接外部服务。
```

### 已观察事件

1. 从 Dashboard 提交需求后进入 `/zh/chat/<project-id>`，项目工作台显示 Good path 任务面板。
2. 运行时间线显示 Alex/工程师角色，最终显示已处理 8 步。
3. 可见活动包含读取 `README.md`、终端检查、写入 `index.html`、再次检查和可视化检查。
4. 文件树出现 `.atoms`、`app/frontend`、`.mgx`、`README.md`、`index.html`、`script.js`、`style.css`、`package.json`、`template_config.json` 和 `DESIGN.md` 等文件。
5. 生成后出现版本 1、完成摘要、预览任务和发布任务；Good path 从 1/2 变为 2/4。
6. App Viewer 提供分享、升级、发布、移动预览、重载查看器、新标签页、控制台和设计工具入口。

## 预览与真实交互

### 已验证

- 生成页面标题为 Stars。
- 点击“换一句欢迎语”后，页面标题从“你好，欢迎来到 Stars！”变为另一条欢迎语，状态变化来自生成页面脚本。
- 只读控制台检查未见 error 或 warning。
- 本次会话的临时预览地址为：
  `https://1644046-294a2aa78e5941d880e18cd734502cf5-4-latest.app.atoms.dev/`

### 产物风险

生成的 `index.html` 仍出现平台默认 favicon/OG 图片外链和“Made by Atoms”标识。由此确定 Stars 必须在文件写入和预览前执行资源 allowlist、默认域名和第三方品牌标识扫描，不能只依赖用户提示词。

## 刷新恢复
