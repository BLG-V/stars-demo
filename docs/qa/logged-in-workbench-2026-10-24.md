## 本地已验证行为

| 能力 | 自动化证据 |
| --- | --- |
| 文本附件 | 当批支持选择、移除；拒绝非白名单、超过 32 KiB、超过当时的 3 个附件上限及合并需求超 4,000 字符；附件正文参与规划和需求持久化。后续本轮已调整为 10 个并加入目录选择，另见附件回归报告 |
| 语音输入 | 模拟开始、停止、转写、权限拒绝；不支持时显示降级提示 |
| 文件夹 | 创建、重命名、删除、同名冲突、侧栏筛选与空状态；删除后项目保留且变为未分类 |
| 刷新恢复 | 项目归类后刷新，文件夹、归类和筛选结果可恢复；API 测试另覆盖服务进程重启后的持久化 |
| 独立新建项目 | 已打开项目后，从非空及空文件夹的新建入口提交需求，得到新的 projectId 并归入选中文件夹；不继续写入旧项目 |
| 最近与全部项目 | 最近视图最多 8 项；测试造数后切回全部，恢复全部 10 项并显示“我的项目”标题 |
| 账户菜单 | 显示已登录邮箱、开关菜单、服务端退出及前端状态清理 |
| 权限 | 未登录拒绝；跨用户读取、修改或将项目归入他人文件夹被拒绝 |
| 生成与预览 | Stub 规划、文件审核、预览按钮交互、文件编辑、快照比较与恢复、运行刷新恢复 |
| 响应式 | 375/768/1280 视口无页面横向溢出；375px 能创建/删除文件夹并打开账户菜单 |
