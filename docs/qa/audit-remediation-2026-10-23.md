## 2. 本次复核额外修复

1. 生成中刷新：恢复 `running` 状态，禁用重复提交，并继续观察原计划；同一运行只保留一个订阅。客户端等待最长 240 秒，超时提供重新连接入口，不自动启动新模型调用。
2. 预览监控作用域：错误监听脚本封装到 IIFE，避免占用生成应用的 `report`、`original` 全局声明。浏览器用例验证同名声明和真实按钮交互可以同时工作。
3. 审核期间的竞态：手工编辑、恢复和删除受存储内忙碌检查保护；批准时再次验证基线文件指纹。重复批准只保存一份变更审计和一个最终 done 事件。
4. 中断恢复：服务启动把遗留 running 任务记为 RUN_INTERRUPTED，保留错误事件和旧文件；已生成的待审核候选可在重启后继续批准。本机制面向当前单 API 服务，不支持多副本自动续跑模型。

## 4. 主要文件

- `stars-demo/server/index.mjs`、`server/schemas.mjs`：计划、审批、事件、输入与文件校验、请求日志。
- `stars-demo/server/storage/{json,mysql,file-changes}.mjs`：持久化运行、状态比较、基线指纹、原子批准和并发保护。
- `stars-demo/server/migrations/002_run_states.sql`：新增运行明细持久化表。
- `stars-demo/src/{main.jsx,api.js,styles.css}`：两次确认、恢复订阅、历史/差异、预览错误、主题化交互。
- `stars-demo/test/`：HTTP、存储和浏览器回归；真实模型验收脚本已适配新审批协议。
- `stars-demo/package*.json`、质量配置、`.github/workflows/stars-ci.yml`、`stars-demo/deploy/`：版本固定、质量门禁、CI 与部署参考。CI 已配置，本地没有远程 CI 执行记录。
