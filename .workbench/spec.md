# 给实现方

Stars 是围绕“生成一个项目并反复检查、修改、恢复”的产品工作台。未登录公开页按 Atoms `/zh` 公开页面逆向结果组织为顶部导航、Hero Composer、能力卡、团队/Agents、信任统计、FAQ 和页脚；登录后进入完整工作台，显示侧边导航、Agent roster、自然语言 Composer、发现/项目/模板入口、运行流、文件树、代码预览和 App Viewer。只参考 Atoms 的布局层次、组件状态和交互方式，品牌、文案、图标和实现均属于 Stars。本轮按用户最新截图调整为科技公司工作台：雾灰画布、白色面板、蓝色主操作、紧凑清晰的无衬线排版；保留桌面外距与列间距 16px、240px 浮动侧栏、20px 侧栏圆角和柔和阴影。公开页与双栏注册界面保留独立视觉层。

本地 `stars-demo` 已接入可配置 API、SSE、JSON/MySQL 存储适配和受限预览。未登录公开页采用顶部导航、居中 Agent 头像组、主标题和圆角 Composer，并提供能力、统计、Agents、FAQ 和页脚模块；登录后恢复完整工作台导航、流程、文件审阅和 App Viewer。主题只改变视觉表达，不扩大生成、发布或数据访问权限。未配置真实模型时，Stub 仅用于开发且页面明确标注。

本次补充登录后工作台的四个交互：附件按钮允许挑选、查看和移除受限文本文件，并把用户明确选择的文件内容作为当前需求上下文；语音按钮通过浏览器 Speech Recognition 将语音转为可编辑文本，Stars 不保存原始音频；侧栏文件夹支持个人范围内创建、重命名、删除与项目归类；个人账户卡片打开邮箱和会话菜单并提供退出登录。附件原文件不单独保存，合并文本会随项目需求/消息持久化。文件夹与项目归属在服务端按会话用户校验，MySQL 与 JSON 开发存储保持一致；删除文件夹后项目回到未分类，最近视图仅取最近更新的 8 项。前批 `20261024T093929Z-workbench` 的云库 004 与公网 10 项工作台烟测见 [前批生产验收](../docs/qa/production-workbench-2026-10-24.md)；当前科技主题与目录导入已部署至 `20261024T123111Z-techworkbench-94ec577`，见 [本次发布记录](../docs/qa/production-techworkbench-2026-10-24.md)。本次未调用真实模型，真实 SMTP、Cloudflare 和麦克风未复测。

## 权限与数据边界

- 访客可查看公开页面；项目、文件夹和账户操作要求有效登录会话。
- 文件夹列表和增删改均以服务端会话用户为准，客户端传入的 ownerId 不可信；项目移动前再次验证项目和目标文件夹属于同一用户。
- 文本附件在浏览器使用格式白名单，最多 10 个、每个不超过 32 KiB，合并后的需求不超过 4,000 字符；文件夹通过浏览器目录选择器读取用户明确选择的文件，保留相对路径，跳过隐藏文件、依赖和构建目录、锁文件；路径与内容均相同的条目不重复添加。服务端只接收并持久化合并需求，不单独保存上传原文件。提示上下文不得绕过现有提示词长度、生成审查或预览隔离。
- 语音识别依赖浏览器/Web Speech API 能力；不支持时提供可访问的原因提示，浏览器识别权限由用户明确授予。浏览器可能使用自己的远程语音识别服务，不得将该功能描述为完全离线处理。
- 账户菜单显示已认证邮箱；退出操作复用服务端 logout 并清空当前前端状态。

## 本轮交付与范围

首屏保持“导航 → 需求输入 → 发现/项目 → 活动与预览”的层级；输入区添加菜单分别启动本地文件、文件夹选择器，附件列表显示路径和移除入口，导入期间禁止重复导入和提交。沿用 React/Vite 与原生 CSS/SVG，不增加组件库或外部字体。主题属于工作台视觉改版；截图中的团队模式、定时任务、连接器和主题市场不属于本轮功能。本轮已完成本地自动化回归、GitHub 推送和 Stars 专属公网发布；发布范围与前批生产验收分别记录。
